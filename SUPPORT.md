# Support

- **A question** about installing, setting up a server or writing a mod:
  [Discussions](https://github.com/enshwick/.github/discussions).
- **Something broken** in a mod or the loader: open an issue in that mod's
  repository, or in [enshwick](https://github.com/enshwick/enshwick/issues)
  for the loader, and attach the logs from `logs/enshwick/` in the game's
  folder. [Where the logs are](https://github.com/enshwick/enshwick/blob/main/book/src/faq.md)
  explains each file.
- **A security problem**: report it privately, as [SECURITY.md](SECURITY.md)
  says.
